# 照合表

各行に対象期間、B1値、A値、B2値、照合方法、証跡ファイル、結果、確認者、確認日時を記録する。金額は税抜・消費税・税込を区別する。

| 区分 | B1→A | A→B2 | 判定の要点 |
| --- | --- | --- | --- |
| 原本 | Access SHA-256、manifest、テーブル行数 | リリース記録のB1原本SHA-256 | 原本と抽出物の対応が追跡できる |
| マスタ | 得意先、商品、価格、対応表 | 件数・主要キー | 重複、参照切れ、意図しない上書きがない |
| 出荷 | ヘッダー数、明細数、日付、数量、税抜、消費税、税込、商品詳細 | A値とB2値 | 締め済み請求の明細参照を壊さない |
| 請求 | 請求年月、明細、税率別税額、税込、状態 | A値とB2値 | 出荷日と請求年月を混同しない |
| 入金・売掛 | 入金日、金額、充当、未充当、開始残高、月次残高 | A値とB2値 | B1の符号付き台帳を実入金と混同しない |
| 在庫 | 開始在庫、ロット、在庫移動、引当、月次残高 | A値とB2値 | 履歴取込で現在庫や確定月次を二重更新しない |
| 酒税 | 移出数量、区分、容量、税率、軽減、申告額 | A値とB2値 | Access保存値とe-Tax方式の採用値を区別する |
| 消費税 | 税率別明細、伝票・請求単位の端数、請求税額 | A値とB2値 | 税率混在を合算再計算しない |
| 帳票・添付 | 件数、ファイル名、必要な帳票を開けること | A値とB2値 | DBと同じ時点のアーカイブを復元する |
| 業務操作 | 出荷、取消、返品、請求締め、入金充当 | 受入試験 | 状態遷移、監査ログ、権限を確認する |
| 実行環境 | テスト結果、Gitコミット、migration状態 | HTTP、コンテナ、migration、scheduler | コード・DB・稼働状態を一組で確認する |

## 過去月・締め済み月の追加照合

変更・削除・過去日付の追加を検出した場合は、通常照合に加え次を行う。

- 影響する請求、請求明細、売掛月次、酒税月次、消費税月次を一覧化する。
- 適用前後の対象外行もハッシュまたは件数・金額で不変確認する。
- 訂正は既存の確定値を無断で上書きせず、訂正理由、承認識別子、監査ログを残す。
- 開始前・対応先なしのB1差分は、業務データを新規作成せず、原値と除外理由を保存する。
