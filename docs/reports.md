# 帳票方針

## 1. 位置づけ

この文書は帳票の出力条件、保存方針、再発行方針を定義する。

## 2. 共通方針

1. 帳票は確定済みまたは締め済みデータから生成する。
2. 発行時点のファイル、形式、パス、サイズ、SHA-256、理由を `report_exports` に保存する。
3. 未確定データから税務帳票、締め帳票を出力しない。
4. 発行済み帳票を再計算結果で上書きしない。

現行実装は帳票ごとに対応形式が異なる。酒税月次申告はTXT、XLSX、PDFに対応し、その他の帳票は主にTXTである。送付履歴は未実装。実装状況は `docs/current-state.md` を参照する。

## 3. 第5段階時点の帳票

第5段階では検証可能な固定TXT帳票を実装済みとする。

* 請求書帳票基礎
* 酒税申告帳票
* 消費税申告帳票
* 売掛月次残高帳票

酒税月次申告については、e-Tax転記確認用XLSX・PDFと版ごとの出力履歴・ダウンロードを追加済みである。その他の帳票のPDF・Excel対応、送付履歴は後続段階で拡張する。

## 4. 将来の帳票強化

9-1では出荷伝票帳票の固定TXT出力を追加する。出荷伝票帳票は確定済み出荷伝票だけを対象とし、出荷確定時に保存された商品、単位、数量、単価、消費税率、酒税見込額のスナップショットを使って生成する。

出荷伝票帳票では以下を保存する。

* `report_exports.report_type`: `shipment`
* 出力形式
* 保存パス
* ファイル名
* MIME type
* ファイルサイズ
* SHA-256
* 出力理由
* 監査ログ

未確定出荷伝票、未対応形式、書き込み失敗は帳票生成失敗として扱う。

9-2では請求書帳票の固定保存と再発行履歴を強化する。請求書帳票は確定済み請求だけを対象とし、請求確定時に保存された明細スナップショットを使って生成する。再発行時は保存パスに一意な発行IDを含め、過去の発行済みファイルを上書きしない。

9-7では帳票共通の再発行履歴、出力理由、ファイル保全検査を追加する。帳票ファイルの存在、ファイルサイズ、SHA-256は `report_exports` を正本として検査する。ファイル欠損、サイズ不一致、SHA-256不一致は保全検査失敗として扱う。

再発行履歴では以下を確認できる。

* 帳票種別
* 対象モデル
* 対象ID
* 出力日時
* 出力理由
* 保存パス
* ファイル名
* ファイルサイズ
* SHA-256

再発行しても過去の `report_exports` と帳票ファイルを削除または上書きしない。
