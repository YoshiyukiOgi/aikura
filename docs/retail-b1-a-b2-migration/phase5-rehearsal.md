# 工程⑤ 隔離環境リハーサル（2026-09-23）

## 検証用対応表の制限

今回の610商品対応表は技術リハーサル専用である。全商品を外部商品、仕入先を検証用、原価を0円として扱い、原本の負の試験価格3件は0円へ置き換えた。実際の外部／蔵分類、蔵商品ID、仕入先、原価、価格、税率を表すものではない。

したがって工程⑤の**技術リハーサルは完了**したが、工程⑥のA構築へ進むには、610商品の承認済み対応表と開始残高・例外73件の業務確認が必要である。検証用対応表をA/B2へ使用してはならない。
