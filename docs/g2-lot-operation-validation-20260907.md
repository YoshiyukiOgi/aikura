# G2 ロット在庫業務フロー検証 2026-09-07

## 結果

専用テストDBで70テスト、378アサーションが成功した。Aの通常DB、B1、B2への書込みは行っていない。

## 対象

- ロット在庫残高、棚卸調整、月次残高、在庫帳票
- 販売外出入、在庫訂正、ロット引当、出荷確定、出荷取消
- 出荷指示、在庫品のロット割当からピッキング・出荷までの接続
- 非在庫品の分割ピッキングと取消、返品と返品ロット分割
- 出荷APIとロット割当API、操作確認用デモSeeder

## 確認した業務規則

1. 在庫対象品は、出荷確定前に出荷数量と一致するロット割当を必要とする。
2. 出荷指示から在庫対象品をピッキングする場合は、出荷ドラフト作成、ロット割当、ピッキング、出荷確定の順とする。
3. ドラフト出荷取消ではピッキングとのヘッダー参照を解除し、未確定ピッキングを取消できる。確定済み出荷取消ではピッキング・出荷指示を履歴として保持する。
4. 返品は元出荷のロットを指定し、複数ロットに分割する場合も元出荷ロットの合計数量と一致させる。
