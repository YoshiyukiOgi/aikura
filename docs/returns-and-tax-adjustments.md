# 返品・戻入時の税務処理ルール

## 目的

販売済み商品の返品を、元伝票の単純な取消ではなく、新しい差分取引として記録する。

消費税の返品処理と酒税の戻入処理は目的と確定時点が異なるため、同じ「取消」で処理してはならない。

## 消費税: 返品・対価の返還

税率改正後に返品があった場合でも、返品の消費税区分と税率は返品日現在のマスタから再解決してはならない。

元の販売・請求で適用した税率を引き継ぐ。

例:

```text
旧税率 8% で販売
  ↓
税率改正
  ↓
返品
  ↓
返品額の消費税は 8% で控除する
```

返品伝票または赤伝には、最低限以下を保存する。

| 項目 | 説明 |
| --- | --- |
| 元出荷明細ID | 返品対象の出荷明細 |
| 元請求明細ID | 返品対象の請求明細 |
| 返品日 | 実際に返品を受けた日 |
| 返品数量 | 返品数量 |
| 返品単価 | 元取引の単価 |
| 消費税区分 | 元請求明細の区分 |
| 消費税率 | 元請求明細の税率 |
| 消費税額 | 元税率と返品金額から計算した控除額 |
| 返品理由 | 返品理由 |

消費税額は、元請求明細の `tax_rate`、`consumption_tax_category_*` を引き継いで計算する。現在の税率マスタや商品マスタを参照して再計算してはならない。

請求書を発行済みの場合は、返品処理に対応する返還・値引の帳票を別途残す。元請求書を上書きまたは削除してはならない。

## 酒税: 戻入

酒類が販売後に戻った場合は、元の移出と関連付けた戻入として記録する必要がある。

戻入は、単に在庫を増やす処理ではない。酒税の移出数量・月次申告・在庫移動に影響する税務上の差分取引である。

戻入伝票には、最低限以下を保存する。

| 項目 | 説明 |
| --- | --- |
| 元出荷明細ID | 戻入対象の出荷明細 |
| 元酒税移出日 | 元出荷で使った `liquor_tax_transfer_date` |
| 戻入日 | 実際に戻入を受けた日 |
| 戻入数量 | 戻入数量 |
| 酒税区分 | 元出荷明細の `confirmed_liquor_tax_*` を基準にする |
| 課税kL | 元の容量・単位・数量に基づく戻入kL |
| 酒税額 | 元の酒税ルール・税率・軽減率を基準にした控除額または調整額 |
| 戻入理由 | 戻入理由 |
| ロット・在庫場所 | 在庫へ戻す先を追跡する情報 |

酒税についても、現在の酒税ルールを再解決してはならない。元出荷明細の `confirmed_liquor_tax_category_*`、`confirmed_liquor_tax_rule_id`、`confirmed_liquor_tax_per_kl`、`confirmed_liquor_tax_reduction_rate` を根拠にする。

酒税月次申告が確定済みの場合は、確定済み出荷を取消してはならない。戻入を新規差分として記録し、税務上の月次処理・訂正申告の要否は税理士または所轄税務署への確認を前提とする。

## 現行システムとの差分

現行システムの `CancelShipmentService` は、出荷伝票を `cancelled` にし、在庫移動を反転する。

これは誤出荷など、出荷を取り消す処理には使えるが、以下を持たないため返品・戻入処理の代わりにはならない。

* 返品日・戻入日
* 一部返品数量
* 元請求明細への参照
* 元取引税率に基づく消費税控除額
* 酒税の戻入kL・戻入税額
* 返品・戻入用の帳票

## 実装方針: 返品・赤伝と販売外在庫出入を分ける

小売店返品の画面では、販売管理上の返品と赤伝を対象にする。

返品・赤伝では以下を扱う。

* 元請求明細への紐づけ
* 返品数量
* 元単価
* 元請求明細の消費税区分・税率
* 赤伝ドラフト
* 返品在庫または通常在庫への入庫
* 販売外在庫出入へ回す判断

返品・赤伝では酒税戻入を確定しない。

戻入、瓶詰、破損、詰替、廃棄など、製造場または販売外の酒類在庫処理は `non_sales_stock_operations` として扱う。

返品由来で製造場側の処理が必要な場合は、返品明細を起点に販売外在庫出入を作成する。酒税戻入控除や廃棄届出などの税務判断は、この販売外在庫出入側で扱う。

## 実装時の受け入れ条件

1. 一部返品を、元出荷を取消さずに登録できる。
2. 税率改正後の返品でも、元請求明細の税率で消費税額を計算できる。
3. 返品による消費税額と税込額を、元請求書とは別の差分として記録できる。
4. 酒類の戻入では、元出荷の酒税スナップショットを引き継いでkL・酒税額を記録できる。
5. 返品・戻入による在庫増加を、元出荷と関連付けた在庫移動として記録できる。
6. 消費税申告または酒税申告が確定済みの期間については、取消ではなく差分・訂正手順へ誘導する。
7. 元伝票、返品伝票、戻入伝票、帳票出力、監査ログを相互にたどれる。
