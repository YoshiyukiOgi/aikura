# コーディング規約

## 1. 基本方針

1. 業務ロジックはService層に置く。
2. Controller、画面、Seederへ中核業務判断を分散しない。
3. 金額、数量、税額、酒税には浮動小数を使わない。
4. 状態変更は専用Service経由で行う。
5. 確定済みデータや締め済みデータを直接更新しない。

## 2. 数値計算

金額、数量、税額、酒税はDBの固定小数精度とPHPの文字列演算で扱う。

`float`、`double`、表示目的以外の丸め済み文字列整形に依存しない。

## 3. テスト

中核ServiceにはFeature TestまたはUnit Testを追加する。
