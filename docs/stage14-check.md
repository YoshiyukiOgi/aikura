# 第14段階 進行確認

## 確認日

2026-05-25

## 14-1 将来拡張方針の整理

第14段階を本番運用試験前の追加実装工程ではなく、将来拡張の境界と判断条件を整理する工程として `docs/future-extensions.md` に定義した。

確認内容:

* 対象を会計連携、仕訳出力、会計ソフト向けCSVまたはAPI出力、製造管理システム連携、原価参照、BI分析、AI分析、音声操作とした。
* 運用試験前には、将来拡張のためだけに本体DB、月次締め、税務確定、帳票、承認フローへ新しい実装を追加しない方針とした。
* 将来参照する元データを壊さず、運用試験後に必要性を判断する方針とした。

## 14-2 会計連携の運用試験後判断

会計連携は、運用試験後に必要性、対象会計ソフト、出力形式、勘定科目体系、税区分、部門、補助科目、締め単位を確認してから実装判断する方針とした。

確認内容:

* 現時点では仕訳テーブル、会計ソフト向けCSV、API連携、仕訳生成ジョブ、会計連携用締め処理を実装しない方針とした。
* 将来連携の参照元として、確定済み出荷、確定済み請求、入金、売掛月次、酒税月次申告、消費税月次申告、在庫移動、在庫月次残高を整理した。
* 取消、訂正、調整の履歴を連携判断の根拠に含める方針とした。

## 14-3 マニフェスト整合チェック

第14段階を将来拡張として凍結し、運用試験前に本体機能へ追加実装しない方針を `docs/manifest.md` に反映した。

確認内容:

* マニフェストの第14段階を 14-1 から 14-3 の明示的な工程へ更新した。
* 会計連携は初期段階で仕訳出力を実装しない方針と整合している。
* 製造管理システムとの境界は、販売管理側が製造ロット参照情報を保持し、詳細製造管理を将来システム側へ分離する方針と整合している。
* 第14段階の後付け可能性は、確定済み業務データ、月次残高、税務申告、帳票、監査ログ、承認履歴が保存されていることを前提とする。
