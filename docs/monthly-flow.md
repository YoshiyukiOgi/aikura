# 月次業務フロー

## 1. 位置づけ

この文書は、月次集計、税務申告、売掛締め、在庫締めの流れを定義する。

第5段階時点では、実装済みServiceとテーブルに合わせて、月次処理を以下の単位で扱う。

* 在庫月次残高
* 酒税月次申告
* 消費税月次申告
* 売掛月次残高

## 2. 共通原則

1. ドラフト作成で集計値を保存する。
2. ドラフトは再計算で上書きできる。
3. 確定済みまたは締め済み月は再計算で上書きしない。
4. 確定または締めには理由を必須とし、監査ログを保存する。
5. 締め済み期間への直接変更は禁止する。
6. 修正が必要な場合は、締め解除または翌月以降の差分処理として扱う。

## 3. 酒税

1. 確定済み出荷明細の酒税保存値を基に、月次酒税移出数量を集計する。
2. 集計月は `liquor_tax_transfer_date` を優先し、未設定の場合のみ伝票日付を使用する。
3. 取消済み出荷は除外する。
4. 月次酒税申告ドラフトを作成する。
5. ドラフトを確定し、見込酒税額を確定酒税額として固定する。
6. 確定済み月は出荷確定・出荷取消で酒税移出数量を変更できない。
7. 確定済み申告から帳票を生成し、`report_exports` に保存する。
8. 旧制度は年度内の軽減対象数量累計と年間上限数量を用いて軽減額を計算する。
9. 新制度は前年最大品目課税移出数量に対応する率区分と、年度内の軽減前税額累計の税額帯を用いて軽減額を計算する。
10. 新制度の課税移出と戻入れは、根拠伝票の日付、伝票番号、明細IDの順で計算し、戻入れは直前累計から税額帯を逆方向にたどって控除額を計算する。
11. 申告明細には累計軽減前税額の計算前・計算後、率区分、適用税額帯、帯内税額、軽減率、丸め前軽減額をスナップショット保存する。
12. Excel・PDF確認表には「軽減計算根拠」を出力し、確定後にマスタ設定を再解決しない。

## 4. 消費税

1. 確定済み請求明細の消費税保存値を基に、請求日付の月で集計する。
2. 取消済み請求は除外する。
3. 月次消費税申告ドラフトを作成する。
4. ドラフトを確定し、消費税額を確定消費税額として固定する。
5. 確定済み月は請求確定・請求取消で消費税額を変更できない。
6. 確定済み申告から帳票を生成し、`report_exports` に保存する。

## 5. 売掛

1. 対象月末以前の請求に紐づく入金予定を集計対象にする。
2. 対象月末以前の取消されていない入金だけを差し引く。
3. 顧客別に予定額、入金済額、未収額、未入金件数、一部入金件数、完了件数を保存する。
4. 売掛月次残高ドラフトを作成する。
5. ドラフトを確定し、月末時点の売掛残高を固定する。
6. 確定済み月は請求確定、請求取消、入金予定作成、入金登録、入金取消で売掛残高を変更できない。
7. 確定済みまたは締め済み残高から帳票を生成し、`report_exports` に保存する。
8. 月次請求締めで確定済み売掛月次残高を `closed` にする。
9. `closed` の `outstanding_amount` を翌月繰越残高の根拠とする。

## 6. 在庫

1. `stock_movements` の `confirmed` および `closed` を集計対象にする。
2. `draft`、`cancelled`、取消日時を持つ在庫移動は除外する。
3. 棚卸対象日と実際の棚卸実施日、棚卸確定日を分けて扱う。翌月に棚卸を数え終えても、棚卸対象日が前月末であれば前月在庫として確定できる。
4. 棚卸差異は `stock_monthly_balances` を直接修正せず、棚卸対象日を `movement_date` とする在庫調整の `stock_movements` として記録する。
5. 月次在庫残高ドラフトを作成する。
6. 月次在庫残高を確定し、対象期間の `confirmed` な在庫移動を `closed` にする。
7. 確定済みまたは締め済み月には新規在庫移動を直接作成しない。
8. 現在庫照会は、長期運用では直近の締め済み月次在庫残高を起点にし、その翌日以降の在庫移動だけを加減算する。
